# Buscador de Receitas

## Autor
Sofia de Carvalho Raimundo — 22401863

## Descrição
Aplicação web que permite buscar receitas de pratos pelo nome e visualizar ingredientes, modo de preparo e categoria de forma organizada.

## API utilizada
Nome da API: TheMealDB — https://www.themealdb.com/api.php
Endpoint consumido: https://www.themealdb.com/api/json/v1/1/search.php?s={termo}

## Funcionalidades
Buscar uma receita pelo nome do prato (em inglês, ex: "chicken", "cake", "pasta")
Visualizar imagem, categoria e origem do prato
Ver a lista completa de ingredientes com as medidas
Ler o modo de preparo
Acessar o vídeo da receita no YouTube (quando disponível)
Mensagem amigável caso o prato não seja encontrado ou a API esteja fora do ar
